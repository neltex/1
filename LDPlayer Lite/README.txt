LDPLAYER LITE (Windows 10)

1. Install LDPlayer 9 from its official website: https://www.ldplayer.net/
2. Extract the LiteDroid ZIP, then double-click "LDPlayer Lite\START HERE.bat".
3. It sets ONE instance to 2 CPU cores / 2 GB RAM / 720x1280 and starts it.
   If YacineTV_____V3.2.apk is next to the LDPlayer Lite folder, it also asks
   LDPlayer to install it. Open YacineTV inside the emulator to verify.

This DOES NOT patch or redistribute LDPlayer. It is a configuration/launch
helper using the vendor's ldconsole.exe. LDPlayer must be installed separately.
Apps run inside an LDPlayer window, not separate native Windows app windows.
If a 2 GB budget is too small for the app, raise it in LDPlayer settings.
